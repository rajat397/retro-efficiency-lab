## Discussion summary

1. **Project thesis** (user): REA's open-source launch led a wave of people reverse
   engineering old, complex, hyper-efficient games/apps; community discussion observed
   that complex systems used to run in KB–MB budgets while modern apps are heavier.
   Hypothesis: rediscover and research the best techniques from old efficient software
   and apply them to modern contexts for impact.
2. **First plan reviewed and rejected** (from another agent): DX-Ball, 90s editor,
   Winamp-era player, Elite, DOS shmup — rejected as low mechanism density; techniques
   textbook or already re-invented.
3. **Rebuilt strategy** (this agent):
   - Selection principle: hard budget + public reconstruction + REA-fit + modern analogue.
   - Slate: Touhou TH04/TH05 → Doom → RCT → Another World / SCUMM / X-COM / KKrieger /
     console ROMs.
   - Mechanism families as extraction buckets (determinism, zero-alloc, data-as-program,
     procedural, streaming, format, lut).
   - Quality gates: single-witness → cataloged (≥2 witnesses) → proven (transfer test
     with numbers).
4. **User directive**: save every useful discussion, decision, and finding; create
   GitHub repo `rajat397/retro-efficiency-lab` and keep pushing.
